# VikACG 去广告（维咔V站）油猴脚本

一个针对 [维咔VikACG](https://www.vikacg.com/)（主站与全部备用域名）的去广告油猴脚本（Tampermonkey / Violentmonkey）。所有去广告动作只隐藏广告元素本身，**不拦截、不改写任何正常链接的跳转**。

## 功能

| 功能 | 说明 |
|---|---|
| 隐藏顶部广告条 | 页头一排站外广告链接 |
| 隐藏轮播/横幅广告图 | 列表页顶部广告轮播（含新版幻灯片结构） |
| 隐藏侧栏广告卡 / 弹窗广告横幅 | 文章页右栏广告卡、搜索弹窗内嵌广告横幅 |
| 隐藏信息流推广卡片 | 带或不带「XX区-推广」角标的广告卡 |
| 隐藏菜单广告链接 | 抽屉/侧栏菜单中的粉色站外广告链接 |
| 隐藏底部下载App横幅 | 含占位条 |
| 广告拦截器检测失效 | 站点会探测 uBlock 等并弹窗（PWA 下甚至暂停渲染），本脚本使其永远检测不到 |
| 拦截自动弹出广告页 | 站点会在投票/收藏/搜索/做任务后自动 `window.open` 打开广告页（`click_source:"auto"`），已拦截；OAuth 登录与用户点击的链接不受影响 |
| 外链直达（可选） | 站点把外链跳转都经过 `/external` 中转页（滚动确认/人机验证/推广 App），开启后直接跳转目标网址。同时兼容新旧两种参数格式：明文 `?url=` 与加密令牌 `?e=`（用站点前端自带的同一密钥经浏览器原生 WebCrypto 解密，不绕过任何验证）；解密失败或目标是站内地址时不动作，交回站点原页面处理 |

脚本内置**内容保险丝**：任何规则都不会隐藏含正文段落/文章容器的元素，详情页推广角标、正文内嵌广告横幅等与内容结构相似的情形一律只清除广告单元本身。

对站点的广告拦截器检测做了双重对抗（同步诱饵护盾保证检测诱饵永远"可见"；弹窗熔断器剥离零宽字符后按中英文文案匹配，即使检测命中也立即移除弹窗）；其余由 DOM 清扫引擎（MutationObserver + 定时兜底）按「广告渲染器指纹」（站外 `a.w-full` + `div.contents` 包裹）识别清除，站点换广告皮肤也能兜住。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）或 Violentmonkey
2. 安装脚本：
   - Greasy Fork：（发布后填入链接）
   - GitHub 直装：点击 [vikacg-adblock.user.js](./vikacg-adblock.user.js) 原始文件安装
3. 打开维咔任意域名即可生效

支持域名：`vikacg.com` / `vikacg.cc` / `vikacg.moe.mov` / `vikacg.eueu.lol`（含 www 与子域）

## 开关

点击油猴图标可逐项开关所有功能（✅/❌ 切换，自动保存）。默认全部开启。

## 常见问题

**Q：为什么用了 uBlock 还会被弹「检测到广告拦截器」？**
A：站点内置了检测（诱饵元素 + 探测请求 + `abp` 标记），uBlock 的通用规则会中招。本脚本从源头让检测失效，即使同时开 uBlock 也不会被弹窗。

**Q：会误伤正常链接吗？**
A：脚本从不拦截、不改写点击事件，只隐藏广告元素。正文里的下载链接、站内导航、OAuth 登录均不受影响。

**Q：点「立即下载」/外链会经过一长串中转页吗？**
A：开启「外链直达」后不会。脚本会直接解出目标地址跳转（含 2026-10 站点改版后的加密令牌格式），帖子的百度网盘 / PikPak 等下载按钮实测可直达。若你在油猴菜单关闭了该功能，则恢复站点原有的中转确认页。

**Q：脚本没生效？**
A：确认你访问的域名在上面的支持列表里；安装/更新脚本后请强制刷新页面（Ctrl+F5）。
